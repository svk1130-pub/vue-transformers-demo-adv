ПРЕЗЕНТАЦИЯ: Vue 3 + transformers.js — учебный SPA-демо
=====================================================

Структура презентации: 3 раздела (Хаб, Детектор, Переводчик), в каждом —
основные блоки страниц. Используйте как основу для слайдов.

------------------------------------------------------------

РАЗДЕЛ 1. ХАБ (HomeView)
URL: http://localhost:5173/

Слайд 1.1: Заголовок и описание
  - Заголовок «Демо нейросетей в браузере»
  - Краткое описание: Composition API, Router, Pinia, Transition-анимации
  - Модели работают в браузере через transformers.js — без сервера

Слайд 1.2: Прогресс-бар изучения
  - Полоса заполняется по мере изучения страниц
  - Кнопка «Сбросить прогресс» (появляется когда есть что сбрасывать)
  - Сохраняется в localStorage

Слайд 1.3: Карточки демо
  - Детектор объектов (Xenova/detr-resnet-50)
  - Переводчик (Xenova/opus-mt-ru-en / opus-mt-en-ru)
  - Staggering-появление через TransitionGroup

Слайд 1.4: Технологии Vue 3 (9 категорий)
  - Ядро Vue 3: Composition API, Router, Pinia, useRoute/useRouter
  - Реактивность: ref, computed, watch, deep, shallowRef, nextTick + rAF
  - Анимации: Transition, mode="out-in", TransitionGroup, list-move, staggering
  - Композаблы и шаблоны: usePipeline, template ref, defineAsyncComponent, markRaw, provide/inject
  - Динамический рендеринг: <component :is>, KeepAlive, Teleport, динамические :class и :style
  - Формы и ввод: v-model на input/textarea/range/checkbox/radio/select, динамический :min
  - Canvas и Web API: Canvas API, clipboard, speechSynthesis, localStorage, color input
  - Стор (Pinia): state/getters/actions, персистенция, storeToRefs, Map как state
  - CSS и дизайн: CSS-переменные, prefers-color-scheme, Grid, media, clip-path, @keyframes, sticky, accent-color

Слайд 1.5: Сайдбар (общий для всех страниц)
  - Навигация: Хаб, Детектор, Переводчик
  - Галочки ✓ у изученных страниц
  - Активная модель (текущая загруженная)
  - Список технологий мелким шрифтом внизу

Слайд 1.6: Тёмная тема (новинка solutions)
  - Кнопка 🌙/☀️ в правом верхнем углу main
  - Переключение CSS-переменных через document.documentElement.style.setProperty
  - Сохранение в localStorage, системная тема по умолчанию (prefers-color-scheme)

РАЗДЕЛ 2. ДЕТЕКТОР ОБЪЕКТОВ (DetectorView)
URL: http://localhost:5173/detector

Слайд 2.1: Заголовок и описание
  - Модель Xenova/detr-resnet-50
  - Находит объекты на изображении, рисует bounding box-ы на canvas
  - Подписи классов с уверенностью модели

Слайд 2.2: Статус модели и прогресс
  - Индикатор: idle / loading / ready / error
  - Прогресс-бар с процентами во время загрузки (166 МБ)
  - Кэш браузера — повторные запуски мгновенны

Слайд 2.3: Зона загрузки изображения
  - Drag&drop + file input
  - 3 кнопки примеров: кот, улица, собака

Слайд 2.4: 3-стадийный степпер загрузки (новинка)
  - ① Загрузка изображения → ② Детекция → ③ Готово
  - Активная стадия — зелёная, пройденная — с галочкой ✓
  - Подпись под степпером анимированно меняется (Transition mode="out-in")
  - При «ничего не найдено» — остаётся с подписью «Готово — ничего не найдено»

Слайд 2.5: Скелетоны во время загрузки (новинка)
  - Мерцающие прямоугольники на месте метрик, порога, шторки
  - @keyframes skeleton-shimmer
  - Плавная смена скелетон → реальный блок через Transition

Слайд 2.6: Метрики объектов (новинка)
  - Найдено: N
  - Уникальных классов: M
  - Средняя уверенность: K%
  - Анимация «перелистывания» чисел при изменении

Слайд 2.7: Слайдер порога уверенности (новинка)
  - Динамический min = наименьший confidence из найденных
  - Шаг 0.1%, max 100%
  - Боксы низкого confidence исчезают с canvas и из списка
  - Сброс при новой детекции

Слайд 2.8: Шторка сравнения «до/после» (новинка)
  - Слайдер 0–100%
  - clip-path: inset(0 X% 0 0) на canvas-overlay
  - Вертикальная черта-граница (бирюзовая)
  - Левая часть с боксами, правая — без

Слайд 2.9: Двухколоночный layout (новинка)
  - Картинка слева (1fr), список справа (280px)
  - Адаптивность: на узких экранах список уходит под картинку
  - Сортировка через <select>: % ↓, % ↑, класс А→Я, класс Я→А

Слайд 2.10: Фильтр по классу + кнопка [x] (новинка)
  - Поиск сразу на 2 языках: «cat» и «кот» найдут одно и то же
  - Кнопка [x] внутри поля, появляется через Transition
  - Отсеивает боксы на canvas, не только в списке
  - Сброс при новой детекции

Слайд 2.11: Управление видимостью боксов (новинка)
  - Чекбокс у каждого элемента списка
  - Кнопки «Показать все» / «Скрыть все»
  - Скрытые строки с opacity 0.4 и зачёркиванием
  - Shift+клик по чекбоксу → color picker, цвет применяется ко всем боксам класса

Слайд 2.12: Выделение бокса по клику (новинка)
  - Клик по боксу на canvas:
    - Первый клик — pill получает рамку цветом класса, бокс — рамка в 2× толще, остальные 40% opacity
    - Озвучка на выбранном языке
  - Второй клик — выделение снято, без озвучки
  - Клик по другому боксу — переключение

Слайд 2.13: Переключатель языка EN/RU (новинка)
  - При RU — названия классов из coco.js (cat → кошка, dog → собака)
  - Сортировка «Класс А→Я» работает на выбранном языке
  - Фильтр ищет по обоим языкам

Слайд 2.14: Озвучка найденных объектов (новинка)
  - Кнопка 🔊 на каждой плашке
  - EN: "With 99.5% probability, it's a cat" (lang=en-US)
  - RU: "С вероятностью 99.5 процентов это кот" (lang=ru-RU)
  - Повторный клик — остановка, onBeforeUnmount — speechSynthesis.cancel()

Слайд 2.15: Drag-and-drop перестановка (новинка)
  - Перетаскивайте элементы списка мышью
  - Цвет боксов на canvas меняется с новым порядком
  - TransitionGroup с list-move — плавная анимация

Слайд 2.16: Вкладка «Как это работает»
  - 7 секций: модель, классы COCO, ограничения, что хорошо, что плохо, эксперименты, викторина
  - Клик по карточке в галерее → автопереход на демо + загрузка
  - Викторина: 3 вопроса, подсветка правильных/неправильных
  - KeepAlive — состояние демо сохраняется между переключениями

Слайд 2.17: Прогресс изучения
  - Посещение «Как это работает» отмечается в Pinia
  - Прохождение викторины — отдельно
  - Галочки ✓ в сайдбаре
  - Сохраняется в localStorage

РАЗДЕЛ 3. ПЕРЕВОДЧИК (TranslatorView)
URL: http://localhost:5173/translator

Слайд 3.1: Заголовок и описание
  - Две модели: Xenova/opus-mt-ru-en и opus-mt-en-ru (по 108 МБ)
  - Грузятся параллельно при открытии страницы
  - MarianMT — encoder-decoder Transformer

Слайд 3.2: Статус модели и направление
  - Индикатор: idle / loading / ready / error
  - Автоопределение направления по наличию кириллицы
  - Кнопка Swap ⇄ — ручное переключение, переставляет input↔output

Слайд 3.3: Поля ввода и вывода
  - Textarea для исходного текста, лимит 500 символов
  - Поле «Перевод» — результат
  - Инкрементальный стриминг по предложениям (TransitionGroup)

Слайд 3.4: SVG-кольцо счётчика символов (новинка)
  - Заменяет текст «35 / 500»
  - Заполняется по мере ввода
  - Цвета: 0–90% зелёный, 90–100% жёлтый, >100% красный
  - Зазор между текстом и кольцом (padding 3px)

Слайд 3.5: Кнопка «Очистить» (новинка)
  - Появляется только когда есть что очищать (Transition)
  - Подтверждение для длинных текстов (>100 символов)
  - Сбрасывает inputText, translatedSentences, manualOverride

Слайд 3.6: Кнопка «Копировать» + toast (новинка)
  - Копирует перевод в navigator.clipboard
  - Иконка меняется на ✓ на 1.5с
  - Toast «Текст скопирован» через Teleport to="body"
  - Рендерится вне DOM-дерева переводчика
  - Продление toast при повторном копировании (clearTimeout)

Слайд 3.7: Кнопка «Озвучить перевод» (новинка)
  - speechSynthesis.speak()
  - Язык соответствует направлению (en-US / ru-RU)
  - Иконка ⏸ во время проигрывания, повторный клик — остановка
  - onBeforeUnmount — speechSynthesis.cancel()

Слайд 3.8: История переводов в Pinia (новинка)
  - Последние 5 уникальных переводов
  - Под полем вывода — раскрывающийся список
  - Клик по элементу — восстановление исходного текста и направления
  - Кнопка «Очистить историю» с confirm()
  - Сохраняется в localStorage

Слайд 3.9: Вкладка «Как это работает»
  - 6 секций: модель, что хорошо, что плохо, технические особенности, эксперименты, викторина
  - Клик по карточке примера → автозапуск перевода
  - Викторина: 3 вопроса про MarianMT

ПРИЛОЖЕНИЕ: Стек и архитектура

Слайд A.1: Стек технологий
  - Vite 6, Vue 3.5 (Composition API, <script setup>)
  - Vue Router 4 (ленивый импорт, ?tab=)
  - Pinia (4 стора: demoStore, progress, history, theme)
  - @huggingface/transformers (transformers.js)
  - Чистый CSS, JavaScript без TypeScript

Слайд A.2: Архитектура
  - usePipeline — единая обёртка над transformers.js
  - DemoPage — обёртка с вкладками (Демо / Как это работает)
  - HowItWorksPanel — рендерер секций через <component :is>
  - 6 компонентов секций: Text, List, Chips, Gallery, Examples, Quiz
  - DetectorPanel / TranslatorPanel — демо-логика
  - DetectorView / TranslatorView — тонкие обёртки с provide

Слайд A.3: Модели
  - Xenova/detr-resnet-50 — детектор (166 МБ, FP32)
  - Xenova/opus-mt-ru-en — перевод RU→EN (108 МБ, q8)
  - Xenova/opus-mt-en-ru — перевод EN→RU (108 МБ, q8)
  - env.useBrowserCache — кэш в IndexedDB
  - env.allowLocalModels + env.allowRemoteModels = false — офлайн

Слайд A.4: Запуск
  - npm install
  - npm run setup (скачать модели + WASM, 384 МБ)
  - npm run dev → http://localhost:5173
