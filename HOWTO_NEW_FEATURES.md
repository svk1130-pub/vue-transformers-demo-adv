# HOWTO_NEW_FEATURES — как пройти по всем новым фичам приложения

Этот документ — пошаговый гид по новым фичам ветки `solutions` (по сравнению
с главной веткой `main`). Пройдите все 16 этапов — увидите каждую новую фишку
в действии.

> Предполагается, что приложение уже установлено и запущено:
> ```bash
> npm install && npm run setup && npm run dev
> ```

## Этап 3. Детектор — степпер загрузки

**URL:** http://localhost:5173/detector

**Что делать:**

1. **Дождитесь загрузки модели** (166 МБ, первый раз 10–30 сек).

2. **Нажмите «Пример: кот»**. Над картинкой появится **3-стадийный степпер**:
   - ① Загрузка изображения (active — зелёный)
   - ② Детекция объектов (pending — серый)
   - ③ Готово (pending — серый)

3. **Следите за стадиями:**
   - Картинка грузится → ① active, подпись «Загрузка изображения…»
   - Картинка загрузилась, начинается inference → ① done (✓), ② active, подпись «Идёт детекция…»
   - Inference завершён → ①② done, ③ active, подпись «Готово — найдено N объектов»
   - Через 1.5с степпер исчезает

4. **Загрузите фото, на котором модель ничего не найдёт** (например, арбуз из галереи «Как это работает»):
   - Степпер останется с подписью «Готово — ничего не найдено»
   - Под степпером — блок «Ничего не найдено на этом изображении»

**Vue-техники:** multi-state `computed` `stage`, `showStepper`, `showDoneStage` с `setTimeout`, `hasFinishedInference` флаг, `<Transition mode="out-in">` для смены подписи

## Этап 6. Детектор — слайдер порога уверенности

**URL:** http://localhost:5173/detector

**Что делать:**

1. **Загрузите картинку** с объектами разной уверенности.

2. **Под метриками — слайдер «Порог уверенности: ≥ N%»**:
   - `min` = наименьший confidence из найденных (например, 45.2%)
   - `max` = 100, `step` = 0.1
   - Под слайдером — счётчик «Показано: 3 из 5»

3. **Двигайте слайдер вправо** — боксы низкого confidence исчезают с canvas, список фильтруется анимированно.

4. **Загрузите новое фото** — порог автоматически сбросится на новый min.

**Vue-техники:** `v-model.number` на range, динамический `:min` через `computed` `minThreshold`, `Math.floor(min * 1000) / 10` для округления, `watch` для перерисовки canvas и сброса

## Этап 7. Детектор — шторка «до/после»

**URL:** http://localhost:5173/detector

2. **Под порогом — слайдер «Шторка сравнения: N% показа боксов»**:

## Этап 10. Детектор — управление видимостью боксов + color picker

**URL:** http://localhost:5173/detector

**Что делать:**

1. **Загрузите картинку** с детекциями.

2. **Кнопки «Показать все» / «Скрыть все»** — над списком.

3. **Чекбокс у каждого элемента списка** — снимите галочку, бокс исчезнёт с canvas. Верните — появится. Скрытые строки с opacity 0.4 и зачёркиванием.

4. **Shift+клик по чекбоксу** — откроется нативный color picker. Выберите цвет — все боксы того же класса перекрасятся.

5. **Клик по боксу прямо на canvas**:
   - Первый клик — pill в списке получает рамку цветом класса, бокс — рамка в 2× толще, остальные боксы 40% opacity. Озвучивается фраза.
   - Второй клик по тому же боксу — выделение снято, без озвучки.
   - Клик по другому боксу — переключение выделения + озвучка нового.

**Vue-техники:** `ref`-массив `boxVisibility`, `ref(new Map())` для `customColors` (пересоздаём для реактивности), `watch` с `{ deep: true }`, `@click` на canvas, масштабирование координат, `addEventListener` для color picker, `ctx.globalAlpha` для 40% opacity, `highlightedIndex` ref

## Этап 14. Переводчик — кнопки «Очистить» и «Копировать» + toast

**URL:** http://localhost:5173/translator

**Что делать:**

1. **Дождитесь загрузки двух моделей** (108 МБ каждая).

2. **Введите текст**, нажмите «Перевести».

3. **Кнопка «Очистить»** (слева от счётчика) — появляется только когда есть контент:
   - Короткий текст — очищает сразу
   - Длинный текст (>100 символов) — `confirm()`

4. **Кнопка 📋 «Копировать»** (справа над полем «Перевод») — копирует перевод в буфер:
   - Иконка меняется на ✓ на 1.5с
   - В правом нижнем углу экрана — toast «Текст скопирован»
   - Toast рендерится через `<Teleport to="body">` — вне DOM-дерева переводчика
   - Повторное копирование — toast продлевается, не «дёргается»

**Vue-техники:** `computed` `hasContent`, `<Transition>` для условного появления кнопки, `<Teleport to="body">` (чисто Vue 3 техника), `:global()` в scoped-стилях, `navigator.clipboard.writeText`, `clearTimeout` для продления toast, `onBeforeUnmount`

## Этап 16. Переводчик — озвучка перевода + история
